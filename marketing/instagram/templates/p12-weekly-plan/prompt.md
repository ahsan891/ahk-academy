# p12-weekly-plan

Make ONE 7-day study plan post for a goal (IELTS speaking, business English, vocabulary, listening, "20 minutes a day"…).

Rules: days in order PZT, SAL, ÇAR, PER, CUM, CMT, PAZ; each task ≤ 52 chars, concrete and time-boxed; Sunday is a review/celebration task; one emoji per day.
