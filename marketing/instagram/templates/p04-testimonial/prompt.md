# p04-testimonial

Make ONE student testimonial post from the details the user provides (name, result, goal, quote). Never invent a real-sounding identity: if details are missing, use "Öğrencimiz" as the name and keep the result generic, and note this in `meta.topic`.

Rules:
- `quote` ≤ 170 chars, first person, Turkish, mentions a concrete before/after moment.
- `result` ≤ 14 chars (e.g. "IELTS 7.5", "B1 → C1"); `result_label` says what it measures.
