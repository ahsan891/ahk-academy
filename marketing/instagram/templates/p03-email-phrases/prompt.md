# p03-email-phrases

Make ONE business-English carousel: 5 email phrases for one situation set (general emails, asking for something, apologising, scheduling meetings, following up, saying no politely, job applications…).

Rules:
- Phrases must be ones natives really write (no "I am writing this email in order to…" clichés unless the topic is formal letters).
- Each phrase ≤ 70 chars; `situation` is a short Turkish label ≤ 26 chars; `tr` is natural Turkish ≤ 80 chars.
- Order them in the order they'd appear in an email (opening → request → … → closing).
