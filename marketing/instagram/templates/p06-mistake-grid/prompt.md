# p06-mistake-grid

Make ONE "3 mistakes" post: three real errors Turkish speakers make (literal translations, preposition slips, verb patterns), each with the wrong version, the right version and a one-line Turkish why.

Rules: sentences ≤ 34 chars, `why` ≤ 70 chars with the rule in **bold**; the 3 mistakes should share a theme if a topic is given (e.g. "at work", "daily life", "IELTS writing").
