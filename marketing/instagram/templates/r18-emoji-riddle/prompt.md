# r18-emoji-riddle

Make ONE emoji riddle Reel: 2–4 emojis that encode a common English idiom or compound word; the viewer guesses, then the answer is revealed.

Rules:
- The emojis must make the answer guessable (literal parts of the idiom work best: 🐘 + 🛋️ → elephant in the room).
- One emoji per array item, no text.
- `answer` ≤ 30 chars, `meaning_tr` ≤ 60 chars, `example` ≤ 80 chars with the idiom in ==double equals==.
