# r03-word-of-day

Make ONE "word of the day" Reel: a useful C1 / IELTS band 7+ word that replaces a basic word Turkish learners overuse (e.g. meticulous, compelling, scarce, alleviate, reluctant, detrimental, thrive).

Rules:
- `word` is a single word, capitalised, ≤ 16 characters. `ipa` with slashes.
- `example` ≤ 80 chars, natural, ideally in an exam/work/daily context, must contain the word.
- `example_tr` is a natural Turkish translation (not word-for-word).
- Synonyms are simpler words the viewer already knows.
- Caption must say which basic word it replaces.
