# r08-never-say

Make ONE rapid-fire Reel with exactly 3 "never say → say instead" upgrades (basic → natural/advanced). Themes: weak "very + adjective", overused "I think", "good/bad/nice", literal Turkish phrases, email clichés.

Rules:
- Each `never` and `say` ≤ 24 characters (they are shown huge; short wins).
- The upgrade must be natural and correct in the SAME context — don't change the meaning.
- `note` is Turkish, ≤ 44 chars.
- If a topic is given (e.g. "business emails"), all 3 pairs follow it.
