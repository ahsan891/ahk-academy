# r11-fill-blank

Make ONE gap-fill Reel (prepositions, since/for, articles, much/many, verb forms, confusing word pairs).

Rules:
- `sentence` has exactly one ___ gap and is ≤ 70 chars.
- 3–4 single-word options ≤ 12 chars, all plausible; `answer` must match one option exactly (same spelling).
- `explanation_tr` ≤ 115 chars, Turkish, contrasts the right option with the tempting wrong one.
